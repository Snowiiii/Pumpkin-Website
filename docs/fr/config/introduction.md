### Configuration

Pumpkin offre un système de configuration robuste qui permet aux utilisateurs de personnaliser différents aspects du comportement du serveur sans se reposer sur des plugins externes. Cela fournit de la flexibilité et du contrôle sur le comportement du serveur.

### Fichier de configuration

La configuration de Pumpkin est stockée dans un seul fichier `pumpkin.toml`.

- `pumpkin.toml`: contrôle tous les paramètres serveur, fonctionnalités, gestion réseau et comportements dans un seul endroit.

Vous pouvez créer `pumpkin.toml` avant de lancer Pumpkin ou le modifier après le premier lancement.

### Version du serveur

Pumpkin a pour but de supporter les dernières versions de Minecraft. Si vous voulez héberger un serveur Pumpkin pour n'importe quelle autre version, il y a un projet appelé [ViaProxy](https://github.com/ViaVersion/ViaProxy).

- Assurez-vous d'autoriser les connections via Proxy
- Pumpkin et ViaProxy ne sont pas liés; ne postez pas de tickets par rapport à leur code. En outre, c'est un Proxy tier et Pumpkin ne prends aucune responsabilité pour le meilleur et pour le pire.

#### Fonctionnalités Clefs

- Vaste personnalisation: Configurez les paramètres du serveur, le comportement des joueurs, la génération du monde et plus.
- Optimisation des performances: Optimisez les performances du serveur à travers des ajustements de configuration.
- Personnalisation sans plugin: Faites les changements désirés sans avoir besoin de plugin additionnels.
