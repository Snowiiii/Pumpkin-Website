# 設定

Pumpkin 提供了一套強大的設定系統，讓使用者無需依賴外部外掛即可自訂伺服器行為的各個面向。這為伺服器的運作提供了彈性與控制能力。

## 設定檔案

Pumpkin 的設定儲存於單一的 `pumpkin.toml` 檔案中。
`pumpkin.toml`：集中控制所有伺服器設定、功能、網路與行為。
您可以在執行 Pumpkin 之前建立 `pumpkin.toml`，或在首次執行 Pumpkin 後再進行編輯。

## 伺服器版本

Pumpkin 的目標是支援最新的 Minecraft 版本。如果您想為其他版本架設 Pumpkin 伺服器，有一個名為 [ViaProxy](https://github.com/ViaVersion/ViaProxy) 的專案可供使用。

請確保允許 Proxy 連線。

Pumpkin 與 ViaProxy 之間沒有任何關聯；請勿提交關於其程式碼的問題回報 (issue)。此外，這是一個第三方 Proxy，Pumpkin 對其任何優劣概不負責。

## 關鍵特色

- **廣泛的自訂功能：** 設定伺服器設定、玩家行為、世界生成等等。
- **效能最佳化：** 透過調整設定來最佳化伺服器效能。
- **免外掛自訂：** 無需額外外掛即可實現所需的變更。
