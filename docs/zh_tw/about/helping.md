# 協助與贊助 Pumpkin

感謝您對支持 Pumpkin 的興趣！無論您是開發者、伺服器管理員，還是 Minecraft 愛好者，都有許多方法可以幫上忙。

## 1. 回報問題與功能建議
如果您在使用 Pumpkin 時遇到錯誤、崩潰或異常行為，開啟 GitHub Issue 能幫助我們快速追蹤並解決問題。
- **檢查現有問題：** 在開啟新工單前，請先搜尋 [Pumpkin GitHub Issues](https://github.com/Pumpkin-MC/Pumpkin/issues) 以避免重複。
- **提供重現步驟：** 包含清晰的步驟、伺服器紀錄、預期與實際行為，以及系統詳細資訊。
- **使用 Issue 範本：** 在 GitHub 上選擇適當的 Issue 範本（錯誤回報或功能請求）。

## 2. 程式碼與文件 Pull Request
我們歡迎程式碼貢獻、文件更新與錯誤修正！
若要貢獻程式碼，請閱讀我們專屬的[貢獻指南](/developer/contributing)，以獲取有關設定環境、反編譯 Minecraft 邏輯以及提交 Pull Request 的完整指示。

> [!IMPORTANT] 程式碼指南
> 在為 Pumpkin 貢獻程式碼時，請遵守我們的專案指南：
> - **遵循 Rust 格式化與 Lint：** 在提交您的 PR 前，請執行 `cargo fmt` 和 `cargo clippy`。
> - **尊重架構規則：** 遵循現有的模組化結構與非同步 (async) 實務。
> - **整潔的提交與 PR：** 保持 Pull Request 專注於單一主題，並附上清晰的提交訊息。
> - **討論重大變更：** 在開發主要功能或進行架構重寫之前，請開啟 GitHub Discussion/Issue，或在[我們的 Discord 伺服器](https://discord.gg/RNm224ZsDq)中與維護者討論。

## 3. 財務支援與贊助
維護並推進高效能的 Minecraft 伺服器軟體需要投入大量的心血與資源。如果您想在財務上支持 Pumpkin 的開發：
- **贊助：** 請前往我們的官方贊助頁面 [pumpkinmc.org/donate](https://pumpkinmc.org/donate) 查看我們的資金募集選項。
- **伺服器基礎架構：** 您也可以透過提供效能評測環境、硬體託管或測試基礎架構來提供協助。

## 4. 社群與支援
加入我們的社群，幫助解答使用者問題、測試預發布功能並交流想法：
- **Discord 社群：** [加入 Pumpkin Discord](https://discord.gg/RNm224ZsDq)
- **GitHub Discussions：** 在 [Pumpkin GitHub Discussions](https://github.com/Pumpkin-MC/Pumpkin/discussions) 上分享回饋與想法
